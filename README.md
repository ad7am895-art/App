# 🕌 تطبيق صلاتي الفاخر - Salatuk Premium App

تطبيق إسلامي عصري متكامل مبني بتقنيات الويب الحديثة (**HTML5, CSS3, JavaScript**)، بتصميم **Glassmorphism** فاخر وزخارف إسلامية. يتيح للمستخدمين معرفة مواقيت الصلاة بدقة، تحديد اتجاه القبلة، قراءة الأذكار، والتسبيح الإلكتروني.

## ✨ المميزات الرئيسية

* 🕋 **مواقيت الصلاة الدقيقة:** جلب التوقيت التلقائي بحسب موقعك الجغرافي عبر API رسمي.
* 🧭 **بوصلة القبلة:** تحديد اتجاه الكعبة المشرفة تفاعلياً عبر مستشعر البوصلة والجيروسكوب.
* 🔔 **منبه الأذان والتنبيهات:** إمكانية تشغيل الأذان مع خاصية الاهتزاز عند حلول الوقت.
* 📿 **مسبحة إلكترونية تفاعلية:** عداد تسبيح ذكي يعتمد التغذية اللمسية (Vibration Feedback).
* 📖 **حصن المسلم والأذكار:** مقسمة بين أذكار الصباح، المساء، وأذكار الصلاة مع عداد القراءة.
* ⚙️ **إعدادات متقدمة:** اختيار طرق الحساب الرسمية (أم القرى، رابطة العالم الإسلامي...) وتخصيص الأصوات.
* 📱 **تطبيق PWA:** دعم التثبيت المباشر على الأجهزة الذكية كـ تطبيق حقيقي دون الحاجة لمتجر متجر تطبيقات.
